NDsoft Speed Doctor · v0.9.0-beta4

Scan. Diagnose. Fix safely. Verify the result.

NDsoft Speed Doctor is a WordPress PageSpeed and Core Web Vitals diagnostic and optimization plugin. Free handles real low-risk fixes; Pro adds AI-assisted planning and a built-in safe Auto Fix engine for deeper issues.

Simple workflow

Scan → Diagnose → AI Fix Plan → Safe Auto Fix → Fresh Verify → Before/After

Free

  • Mobile + Desktop PageSpeed scans
  • Core Web Vitals/Lighthouse diagnostics
  • Compatibility and frontend asset mapping
  • Low-risk one-click fixes
  • Cache-aware verification and rollback
  • Before/After comparison
  • Recent scan history

Pro

  • OpenAI-assisted performance fix plans
  • Built-in safe MCP-compatible Auto Fix engine
  • Managed low-risk execution allowlist
  • Conditional plugin-owned CSS/JS loading rules
  • Frontend validation after changes
  • Rollback support
  • Fresh PageSpeed verification after fixes

No separate MCP plugin, URL or token is required for normal Pro use.

Focused beta: v0.9.0-beta4 intentionally does not include scheduled PageSpeed monitoring or score-drop email alerts. Users run scans when they need them and receive the complete report immediately in WordPress.

Safety first

Automatic execution is restricted to allowlisted low-risk actions. Medium/high-risk recommendations remain review-first. Cache purge, frontend structural validation, and rollback are part of the safe execution workflow.

Performance statement: NDsoft Speed Doctor is designed to improve PageSpeed and Core Web Vitals, but it does not guarantee a specific score. Results depend on hosting, themes, plugins, third-party scripts, fonts, media, and external services.
