# NDsoft Speed Doctor v0.9.0-beta4

Public Beta release focused on a short, safe workflow:

**Scan -> Diagnose -> Fix Safely -> Verify -> Roll Back if Needed**

## Package

- `ndsoft-speed-doctor-0.9.0-beta4.zip` - Free WordPress plugin

Install it through **WordPress Admin -> Plugins -> Add New Plugin -> Upload Plugin**.

## Beta4 improvements

- Simplified Auto Fix around built-in safe actions.
- Added the AI Fix Plan workflow.
- Reduced manual MCP setup for normal Auto Fix use.
- Improved rollback and fresh verification.
- Added compatibility-aware optimization behavior and warnings.
- Improved usability across the diagnostic and fix workflow.
- Continued multi-site beta testing.
- Removed scheduled PageSpeed monitoring and score-drop email alert positioning from the current beta workflow.

Recent scan history, Before vs After comparison, and supported safe optimization actions remain available for on-demand workflows.

## Performance note

No specific PageSpeed score is guaranteed. Results depend on hosting, themes, plugins, media, third-party scripts, caching, and network conditions.
