# NDsoft Speed Doctor v0.9.0-beta4

Market-beta release focused on:

**Scan -> Diagnose -> AI Fix Plan -> Safe Auto Fix -> Fresh Verify -> Before/After**

## Package

- `ndsoft-speed-doctor-0.9.0-beta4.zip` - Free WordPress plugin

The Free edition provides PageSpeed diagnostics, Core Web Vitals analysis, compatibility checks, safe optimization controls, scan history, and verification tools.

The optional Pro beta extends the workflow with AI Fix Plan, built-in Safe Auto Fix, conditional asset optimization, advanced optimization workflow, validation, and rollback/reversible changes. Pro beta features remain under active testing.

## Beta4 improvements

- Removed Scheduled PageSpeed Monitoring.
- Removed WordPress cron monitoring jobs.
- Removed score-drop email alerts.
- Removed the monitoring test/settings UI.
- Added cleanup for legacy beta3 monitoring cron events and options.
- Recent Scan History remains available.
- AI Fix Plan remains available in Pro beta.
- Built-in Safe Auto Fix remains available in Pro beta.
- Conditional asset optimization, validation, and rollback remain available in Pro beta.
- Simplified the overall workflow for easier installation and everyday use.

Recent scan history, Before vs After comparison, and supported safe optimization actions remain available for on-demand workflows.

## Performance note

NDsoft Speed Doctor does not guarantee a specific PageSpeed score. Results depend on hosting, themes, plugins, media, third-party scripts, caching, and network conditions.
