# NDsoft Speed Doctor v0.9.0-beta4

Market-beta release focused on a short, safe workflow:

**Scan → Diagnose → AI Fix Plan → Safe Auto Fix → Fresh Verify → Before/After**

## Packages

- `ndsoft-speed-doctor-0.9.0-beta4.zip` — Free core
- `ndsoft-speed-doctor-pro-0.9.0-beta4.zip` — optional Pro add-on

Install and activate Free first, then Pro when Pro features are required.

## What changed from beta3.x

- Removed Scheduled PageSpeed Monitoring.
- Removed WordPress cron monitoring jobs.
- Removed score-drop email alerts.
- Removed the monitoring test/settings UI.
- Pro activation clears legacy beta3 monitoring cron/options.
- Recent Scan History remains available.
- AI planning, built-in safe Auto Fix, conditional asset rules, validation and rollback remain available in Pro.

## Beta note

The beta Pro entitlement is for controlled market testing. Stable 1.0 will use the selected commercial licensing/update mechanism.

## Performance note

No specific PageSpeed score is guaranteed. Results depend on hosting, themes, plugins, media, third-party scripts and external services.
