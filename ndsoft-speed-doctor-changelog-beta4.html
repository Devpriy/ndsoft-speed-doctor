NDsoft Speed Doctor Changelog

Public beta release history for the Free core and its documented workflow.

v0.9.0-beta4 — Public Beta

  • Simplified Auto Fix around built-in safe actions.
  • Added the AI Fix Plan workflow.
  • Reduced manual MCP setup for normal Auto Fix use.
  • Improved rollback and fresh verification.
  • Added compatibility-aware optimization behavior and warnings.
  • Improved usability across the diagnostic and fix workflow.
  • Continued multi-site beta testing.
  • Removed scheduled PageSpeed monitoring and score-drop email alert positioning from the current beta workflow.

v0.9.0-beta3 / beta3.1

  • Introduced self-contained built-in MCP-compatible Auto Fix; separate connector no longer required for normal use.
  • Added managed safe allowlist, site-local endpoint/token for optional advanced access, conditional asset rules, and rollback.
  • Added fail-safe Pro bootstrap handling and in-process native Auto Fix execution.

v0.9.0-beta2

  • Added deterministic MCP preflight actions and capability checks.

Earlier foundation

v0.1–v0.5 established PageSpeed diagnostics, Lighthouse metrics, compatibility awareness, safe-fix cards, snapshots, cache purge, frontend validation, rollback, Free/Pro capability gates, and AI/MCP extension architecture.
