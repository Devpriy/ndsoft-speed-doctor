# Contributing

Thank you for helping improve NDsoft Speed Doctor.

## Bug reports

Please reproduce the issue first and include:

- WordPress version
- PHP version
- NDsoft Speed Doctor version
- Active theme
- Relevant plugins
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots or sanitized logs when useful

Never include passwords, API keys, access tokens, private keys, database credentials, or other secrets.

## Changes

Keep changes focused, explain the user-facing effect, and avoid including private site data in code, tests, screenshots, or reports. Test WordPress-facing changes against the supported environment when possible.
