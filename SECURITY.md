# Security Policy

## Responsible disclosure

Please report suspected security vulnerabilities privately to NDsoftDesign before public disclosure. Include the affected version, a concise description, reproduction steps, and the minimum sanitized evidence needed to investigate.

Do not publicly post or attach:

- API keys
- Access tokens
- Passwords
- Private keys
- Database credentials
- SMTP credentials
- Private site reports containing secrets

Please remove or redact sensitive values from logs, screenshots, exports, and system reports before sharing them.

## Scope

This policy applies to the public NDsoft Speed Doctor Free source and its released documentation. Do not submit credentials or other private production data as part of an issue or report.
